# /living-doku-update

Zieht die kanonische Living Documentation nach.

## Ablauf
1. Quelle finden (`/wissen-ansehen` zeigt, wo die Doku liegt).
2. Nur nachweislich geänderte Seiten aktualisieren: Entscheidungen, Risiken, Testnachweise.
3. Verknüpfte Todos mit `/todo-link` prüfen.
4. Private Quellen werden nicht kopiert oder veröffentlicht.
5. Kurzbericht mit Datei und Grund je Änderung.
