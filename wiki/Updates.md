# Update-Befehle

- `/skill-update`: Prüft alle lokalen MGD-Skills. ✅ aktuell, ☑️ Update da, ⚠️ lokale Anpassung. Mit `--apply` aktualisieren (vorher Sicherung).
- `/repo-update`: README, Wiki, Skill-Empfehlungen, Version im CHANGELOG, Release und bei Bedarf ZIP-Paket.
- `/MGD-update`: erst GitHub → lokal, dann lokal → GitHub.

**Sicherheit:** Nichts wird gelöscht. Tags und Releases bleiben bestehen. Keine Zugangsdaten.
