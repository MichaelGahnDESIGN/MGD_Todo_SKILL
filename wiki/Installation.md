# Installation

1. Skill holen (Claude Code):
   ```bash
   git clone https://github.com/MichaelGahnDESIGN/MGD_Todo_SKILL.git ~/.claude/skills/todo
   ```
2. Für Codex den Ordner nach `~/.codex/skills/todo` legen.
3. In deinem Projekt `/todo` eingeben und den Ort der Datei nennen, z. B. `TODO/TODO.html`.

**Aktualisieren:** `/skill-update` (holt die neueste Version von GitHub, sichert vorher).
